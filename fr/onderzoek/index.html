Derrière les chiffres

Une rubrique permanente pour ceux qui veulent regarder derrière les données. C’est ici que prennent place les textes trop fouillés pour le journal principal — analyses, rapports, exercices de réflexion et démonstrations empiriques qui nourrissent les articles de fond.

Enrichi en permanence · Indépendant · Regard ouvert

Wat is dit?

Pour ceux qui veulent voir les chiffres

Les articles de fond de chaque édition racontent l’histoire. Vous trouverez ici le travail qui les sous-tend : les analyses de données, les vérifications empiriques et les exercices de réflexion qui ne se prêtent pas toujours à une formulation formelle. Certains textes sont des documents de travail personnels — nous les signalons clairement comme tels. D’autres sont des analyses achevées fondées sur des sources publiques (CBS, AMECO, OECD).
