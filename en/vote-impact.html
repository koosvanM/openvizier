A matrix file as a mirror of politics

Using exclusively AI-researched data from the press and other public information streams, I have built a matrix file that, through multiplication, produces the outputs you see. On one side, the lists of political parties. On the other, the position of the individual. And beneath both, the baseline on which the country stands.

The structure

Each country is modelled along three axes. First, the party lists: per party, a position (from against to in favour) and an intensity (from 0 to 10) on each of the hundreds of consequence elements. Second, the personal position: sector, housing, family, income, age, background, priority — the seven questions the app asks. Third, the baseline on which the country stands, built from geography, population, industry, services, demographic structure, previous decisions by prior governments and other structural pressures that push the real purchasing power of an average household down or up every day.

The core in one line:
Party × Person × Baseline = Projection
Result per order over 15 years, corrected for scenario neutralisation and reference models (VMP, CARB).

Why this approach works

The strength of a matrix is that any change to one input immediately propagates through every outcome. There is no ideological filter and no editorial preference; only the data and the calculation rules determine what appears. Every reader who answers seven questions gets their own projection — an average renter in the private market with a family and a middle income reads a different outcome than a retired owner without a mortgage in the same region. Yet both see the same baseline and the same party lists. The difference lies in the multiplication.

Continuously recalculated

The file is structured so that a recalculation is made at regular intervals, incorporating changes to the inputs. New press reports, new figures from central banks and statistical offices, new party positions or new scenario elements are added at fixed moments, after which the projections adjust automatically. The rule set itself is codified in 84 rules (version 2.3, 2 July 2026) so that each country version demonstrably meets the same structure.
