Поддержка ИИ

«Открытое забрало» использует ИИ для:

  • Перевода статей на немецкий, английский и русский языки (с последующей вычиткой человеком).
  • Первичной фильтрации читательских откликов на спам и оскорбления.
  • Еженедельных резюме с наиболее острыми контраргументами.

Конфиденциальность

«Открытое забрало» собирает минимум данных:

  • Никаких файлов cookie, кроме технически необходимых (например, для виджета обсуждений и языковых предпочтений).
  • Никакой слежки — ни Google Analytics, ни Facebook Pixel, ни рекламных сетей.
  • Подписка на рассылку: хранится только Ваш адрес электронной почты с двойным подтверждением. Отписаться можно в любой момент.
  • Обсуждения: осуществляются через авторизацию GitHub (Giscus). Ваши данные остаются у GitHub согласно их политике конфиденциальности; мы получаем только имя пользователя и текст отклика.
  • Никакой продажи и никакой передачи данных третьим лицам, кроме случаев, предусмотренных законом.
